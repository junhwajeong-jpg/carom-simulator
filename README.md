# Jun's Carom · 4구 물리 시뮬레이터 (모바일)

실제 크기 비율의 4구 당구 물리 시뮬레이터입니다. (mobile 2.1)

- 실행: https://junhwajeong-jpg.github.io/carom-simulator/
- 아이폰: Safari로 열고 공유 버튼 → 홈 화면에 추가
- 안드로이드: Chrome으로 열고 메뉴 → 앱 설치

## 2.1
- 회전 물리(베타): 당점(상하·좌우, 최대 3팁)에 따른 밀림·끌림과 쿠션 반응. 메뉴 → 물리 설정에서 켭니다.
- 클래식(무회전) 물리 설정 범위 확대
- 미션 108개는 클래식 엔진으로 진행

## 2.0
- 미션 108개 (150 중수 / 200 고수 / 300 프로 과정, 유형 12가지), 완료하면 승급
- 수구 궤적만 표시, 배치용 큰 확대경, 첫 사용 안내
- 업데이트: 앱을 열 때 자동으로 최신 파일을 받고, 메뉴 → 정보에서 직접 확인 가능
